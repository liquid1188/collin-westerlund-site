What this does

Each row is one saved change, newest first. Restore puts the whole site back to how it was right after that change, as a new saved version. It rebuilds within about two minutes. If you restore too far, restore the newer one again. Nothing is ever deleted from this list.

Restoring asks for the same access token you use to sign in to the editor. It is kept in this browser only.
